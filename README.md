# Мастер-класс по LLM-театру

В рамках мастер-класса мы посмотим, как агенты могут писать, читать и ставить пьесы.

## Первоначальная установка

Для работы вам потребуется установленный на компьютере кодинг-агент. Мы рекомендуем установить [OpenCode Desktop](https://opencode.ai/desktop). Он включает в себя какое-то количество бесплатных токенов, которые обновляются ежедневно.

Для работы в рамках мастер-класса используйте временный доступ к моделям в Yandex Cloud. Скачайте файл [opencode.json](https://storage.yandexcloud.net/shwars/temp/opencode.json) и поместите его в домашнюю директорию `~\.config\opencode`. После этого в OpenCode должны появиться несколько моделей Yandex.

## Пишем первую пьесу

Для начала, попросим агента написать пьесу самостоятельно:

* Выбираем каталог проекта
* Переходим в режим планирования
* Просим:

> Напиши пьесу про конфликт поколений в мире ближайшего будущего: сын хочет сделать кибермодификацию мозга и уйти на вечную жизнь в киберпространство, родители переживают и хотят его удержать. Давай вместе продумаем основной конфликт, сюжет, главных персонажей, их визуальное описание и особенности речи, особенности мира будущего, специальный сленговые слова и т.д. Напиши текст пьесы в директории `play` в формате Markdown (разбитый на акты), также поддерживай актуальную версию графа пьесы в виде markdown-файлов в директории `wiki`, включая `wiki\protagoninsts` (действующие лица), `wiki\events` (события пьесы), `wiki\places` (основные места). Все узлы wiki должны быть связаны между собой, чтобы прослеживались чёткие причинно-следственные связи между событиями. В страничках wiki должны быть ссылки на текст пьесы.

## Генерируем спекталь

Для генерации спектакля нам понадобится возможность генерации изображений. Для этого можно воспользоваться временным скиллом, использующим Yandex ART, который надо установить командой:

> Установи skill imagen-yart из https://github.com/llm-theater/skills.

Далее попросим модель сделать кукольный спектакль 

> Сделай по пьесе кукольный спектакль, в котором нарисованные фигурки персонажей на прозрачном фоне двигаются перед статическим фоном, реплики возникают в bubbles над головами. Сам спектакль оформи как статическое веб-приложение, запускаемое на локальном компьютере.

## Смотрим структуру сюжета

Попросим агента сделать приложение, которое позволит нам наглядно наблюдать за структурой сюжета и персонажами. Для этого скажем:

> Сделай браузер для wiki и текста пьесы в виде статического веб-приложения, которое можно запускать локально. Он должен показывать персонажей, события, связи между ними, все в виде графа или нескольких графов.

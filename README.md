# Мастер-класс по LLM-театру

В рамках мастер-класса мы посмотим, как агенты могут писать, читать и ставить пьесы.

## Первоначальная установка

Для работы вам потребуется установленный на компьютере кодинг-агент. Мы рекомендуем установить [OpenCode Desktop](https://opencode.ai/desktop). Он включает в себя какое-то количество бесплатных токенов, которые обновляются ежедневно.

Для работы в рамках мастер-класса используйте временный доступ к моделям в Yandex Cloud. Скачайте файл [opencode.json](https://storage.yandexcloud.net/shwars/temp/opencode.json) и поместите его в домашнюю директорию `~\.config\opencode`. После этого в OpenCode должны появиться несколько моделей Yandex.
